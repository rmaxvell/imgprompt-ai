How it works

Three steps to the perfect prompt

No complex setup. No API knowledge required.

1

Hover over any image

The 🔮 button appears automatically on any image on any webpage.

2

Click Prompt

One click sends the image to your chosen AI model for analysis.

3

Copy & create

Features

Everything you need

🖼️

Any image, any site

Works on all websites — images, artworks, photos, screenshots. Even video frames from YouTube and Vimeo.

🦙

Local AI — no API key

Use Ollama, LM Studio or Jan on your own hardware. Fully offline, completely private.

📐

Auto image compression

Images are automatically resized to 1024px and compressed before sending — saves bandwidth and memory.

⏱️

Cancel anytime

Waiting too long? Hit Cancel in the side panel. Smart timeouts: 120s local, 60s cloud.

🕒

History panel

All generated prompts are saved in the side panel. Search, copy or delete them anytime.

🌐

3 output languages

Generate prompts in English, Russian or Chinese — choose in Options.

🔐

Privacy first

No backend server. Your API key is stored only in your browser. Nothing is collected.

✏️

Custom system prompt

Override the default analysis instructions with your own prompt in Options.
